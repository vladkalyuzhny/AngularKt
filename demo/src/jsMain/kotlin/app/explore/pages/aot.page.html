Entry point — src/jsAot/kotlin/main.kt exports main:

Serve with live reload on Kotlin edits — one command, then build for production:

  • The processor generates main.ts and calls your exported main with the compiled root component + router providers.
  • aotConfig.bootstrapComponent decides what that generated entry does: set → standalone bootstrapApplication; unset → classic bootstrapModule of your root @NgModule. The JIT entry is hand-written, so it has no such knob.
  • Templates are compiled to JavaScript at build time, with full type-checking.
  • aotServe runs the dev server plus a background recompile-on-edit; the server reloads when the new Kotlin lands.
  • Selected automatically by running an aot* task.
