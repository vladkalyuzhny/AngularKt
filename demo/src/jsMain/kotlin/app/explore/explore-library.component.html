  1. 1 · Connect Gradle

    Apply the plugin and add the runtime — the plugin pulls in the Angular toolchain and the @angular/* packages.

  2. 2 · Configure the build

    One main entry is picked per mode — wire in only that mode's source directory (each holds its own main.kt).

  3. 3 · Write a component in Kotlin

    The same decorators as Angular — @Component, @NgModule — on Kotlin classes.

Then run it in JIT or AOT mode — see the two tabs above.

Start the dev server:

  • Templates are compiled in the browser by @angular/compiler.
  • zone.js + the compiler are prepended via webpack.config.d/angular-jit.js.
  • Default mode: any task that isn't aot* runs JIT.

Entry point — src/jsAot/kotlin/main.kt exports main:

Serve ahead-of-time, or build for production:

  • The processor generates main.ts, which calls main with the compiled AppModule bridge.
  • Templates are compiled to JavaScript at build time, with full type-checking.
  • Selected automatically by running an aot* task.

For AOT, list global stylesheets and scripts in the angularKt block — they are added to the generated angular.json:

For JIT, mirror the same assets in webpack.config.d/angular-jit.js so webpack injects them:

  • Each entry is a project-relative path (src/jsMain/resources/custom-theme.css) or a bare npm specifier (highlight.js/styles/github.css).
  • App-wide CSS variables can also live in a <style> block in resources/index.html — it is copied into both builds.
